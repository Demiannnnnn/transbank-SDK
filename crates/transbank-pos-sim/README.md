# transbank-pos-sim

> **Unofficial — not affiliated with Transbank S.A.** "Transbank" is a trademark of its owner and is used only to describe compatibility.

Simulator of a Transbank POS terminal for testing applications built on [`transbank-pos`](https://crates.io/crates/transbank-pos) without hardware: a sans-IO simulator, an in-memory transport and a TCP server (`tbk-pos-sim`).

**Status:** early development.

See the [project README](https://github.com/Demiannnnnn/transbank-SDK#readme).
