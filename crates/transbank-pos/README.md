# transbank-pos

> **Unofficial — not affiliated with Transbank S.A.** "Transbank" is a trademark of its owner and is used only to describe compatibility.

Rust SDK for Transbank POS terminals (POS Integrado and POS Autoservicio) over a serial port or TCP: framing, link handling (ACK/NAK, timeouts, retries) and typed commands (sale, last sale, refund, totals, sales detail, close).

**Status:** early development; not yet validated against a real terminal.

See the [project README](https://github.com/Demiannnnnn/transbank-SDK#readme) for usage, documentation and the protocol specification.
